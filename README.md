# Portfolio de Lautaro Berca

Portfolio estático con una paleta azul, negra y roja.

## Cómo verlo

Abrí `index.html` con doble clic. No requiere instalación ni servidor.

## Stack

- HTML semántico
- CSS responsive, modo claro/oscuro y animaciones
- JavaScript vanilla para el menú móvil, el texto animado, el revelado al desplazarse y el fondo de partículas

## Archivos

- `index.html`: contenido y secciones
- `styles.css` y `reference.css`: estilos, colores y adaptación a distintas pantallas
- `app.js`: interacciones y animaciones
- `assets/lb-monogram.svg`: avatar con las iniciales de Lautaro Berca
- `favicon.svg`: ícono del sitio

Las tipografías se cargan desde Google Fonts con conexión a internet; sin ella se usan alternativas instaladas en el sistema.

El email no estaba entre los datos recibidos, así que los enlaces de contacto llevan a LinkedIn y GitHub.
